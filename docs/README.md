# Documentation Assets

This directory contains visual assets for the project documentation.

## Directory Structure

```
docs/
├── screenshots/     # Static screenshots for documentation
│   ├── dashboard.png
│   ├── chat.png
│   ├── upload.png
│   └── datasets.png
│
└── gifs/            # Animated GIFs demonstrating features
    ├── upload-dataset.gif
    ├── ask-questions.gif
    ├── kaggle-download.gif
    └── datasets-management.gif
```

## Adding Screenshots

1. Take screenshots of key features
2. Name them according to the structure above
3. Ensure images are optimized (recommended: PNG for screenshots, GIF for animations)
4. Update README.md references if filenames change

## Creating GIFs

Recommended tools:
- **Windows**: [ScreenToGif](https://www.screentogif.com/)
- **macOS**: [Kap](https://getkap.co/) or QuickTime + [Gifski](https://gif.ski/)
- **Linux**: [Peek](https://github.com/phw/peek) or [Byzanz](https://github.com/GNOME/byzanz)

Tips:
- Keep GIFs under 5MB for web performance
- Use 10-15 fps for smooth animations
- Capture relevant portions of the screen only
- Add captions if needed
